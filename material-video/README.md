# Material para el video de presentación

Esta carpeta reúne el guion y todas las imágenes necesarias para grabar la presentación final sin buscar recursos en distintas ubicaciones del proyecto.

## Contenido

- `GUION_VIDEO_PRESENTACION.md`: narración cronometrada para una duración aproximada de 6 minutos y 35 segundos.
- `imagenes/01-arquitectura-general.png`: arquitectura lógica de la solución.
- `imagenes/02-flujo-batch.png`: procesamiento y recuperación de los jobs.
- `imagenes/03-seguridad-oauth.png`: emisión, propagación y validación del token.
- `imagenes/04-transferencia.png`: transferencia idempotente y compensada.
- `imagenes/05-retiro-atm.png`: secuencia del retiro por cajero.
- `imagenes/06-despliegue-local.png`: topología local con Docker Compose.
- `imagenes/07-arquitectura-aws.png`: arquitectura AWS propuesta, no desplegada.
- `imagenes/08-evidencia-pruebas-maven.png`: resultado de pruebas y compilación.
- `imagenes/09-evidencia-eureka-servicios.png`: registro y escalamiento en Eureka.
- `imagenes/10-evidencia-docker-kafka.png`: contenedores y particiones Kafka.
- `imagenes/11-evidencia-flujo-funcional.png`: seguridad, transferencia, retiro y consumo Kafka.

## Orden recomendado para la grabación

1. Portada del informe final.
2. Arquitectura general.
3. Evidencia de pruebas Maven.
4. Evidencia de Eureka.
5. Evidencia de Docker y Kafka.
6. Evidencia del flujo funcional.
7. Arquitectura AWS propuesta.
8. Página principal del repositorio para el cierre.

Las demás imágenes quedan disponibles como apoyo si se necesita explicar con mayor detalle el procesamiento batch, la seguridad, la transferencia, el retiro o el despliegue local.

## Archivo pendiente

Después de grabar, incorporar en la carpeta final de entrega el video `PBY2203_EFT_S9_Cristian_Nahuas.mp4`. El MP4 debe durar entre 5 y 7 minutos, mostrar la webcam y cubrir los cuatro puntos indicados en el guion.
